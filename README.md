## 便宜美国 VPS 选购时，内存比 CPU 数量更值得先看

BandwagonHost 的官方页面使用类似“2x Intel Xeon”“3x Intel Xeon”的方式展示 CPU 配置，同时列出内存、存储、流量和链路速度。

实际选购时，建议按照下面的顺序判断：

### 先看内存

内存决定了同一时间可以运行多少服务。1 GB 适合轻量环境，2 GB 适合基础网站和小型应用，4 GB 以上才更适合多服务部署。

### 再看流量

1 TB 月流量对普通博客通常够用，但如果网站图片较多、存在文件下载、视频分发或大量 API 请求，就需要预留余量。

流量不是越多越好。一个访问量很低的网站，即使买了 6 TB 月流量，也不一定能改善访问速度。相反，如果网站需要分发大文件，流量额度就比多 1 GB 内存更重要。

### 最后看存储

20 GB SSD 足够安装系统和运行小型网站，但日志、数据库、备份和 Docker 镜像会持续占用空间。40 GB 或 80 GB 对长期使用更宽松。

存储还要考虑备份。假如服务器只有 20 GB 磁盘，却需要保留多份网站备份，空间很快就会见底。把备份放到对象存储或其他服务器，通常更合理。
